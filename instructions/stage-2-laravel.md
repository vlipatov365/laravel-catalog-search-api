# Этап 2 — Установка Laravel: объяснения концепций

## `artisan`

`artisan` — командная строка Laravel. Файл лежит в корне проекта, через него выполняются все служебные команды:

```bash
php artisan migrate        # запустить миграции
php artisan make:model     # создать модель
php artisan route:list     # показать список роутов
```

Аналог `npm run` в Node.js или `manage.py` в Django.

---

## Зачем `APP_KEY`

Laravel шифрует сессии, cookies и чувствительные данные. Для этого нужен секретный ключ — `APP_KEY`. Без него приложение не запустится в продакшене.

```bash
php artisan key:generate  # генерирует ключ и записывает в .env
```

Выполняется один раз при установке.

---

## Как Laravel читает `.env`

`.env` — файл с конфигурацией окружения (ключи БД, пароли, режим отладки). **Никогда не коммитится в git.**

В репозитории хранится `.env.example` — шаблон без значений. Новый разработчик копирует его и заполняет своими данными.

Доступ к значениям в коде:
```php
env('DB_HOST')         // напрямую из .env
config('database.host') // через конфиг-файл (предпочтительно)
```
